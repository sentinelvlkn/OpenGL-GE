# Project Documentation

This folder contains technical documentation for the game engine.

These docs explain:
- the engine's structure
- game rooms authoring
- how Blender data is converted to runtime data
- what main functions do
- how to build and debug the project

## Documentation files

- **ENGINE_OVERVIEW.md**: High-level explanation of the engine systems and render flow
- **FUNCTION_REFERENCE.md**: Important functions and what they do
- **BLENDER_PIPELINE.md**: Blender naming, exporting rules, coordinate conversion and room setup
- **ROOM_JSON_FORMAT.md**: Supported room JSON fields and examples
- **UI_AND_DEBUG_TERMINAL.md**: FreeType text, UI rectangles, prompts and in-game debug terminal
- **BUILD_AND_DEPENDENCIES.md**: Build steps, dependencies and platform notes
